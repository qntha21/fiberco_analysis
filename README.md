# Link Net Technical Assessment: Data Analyst & Visualization role

Analysis of FiberCo's infrastructure monetization, ServCo performance and media attach across 20 fibernodes and 1,000 homepasses, January to December 2025.

**Interactive dashboard:**
https://public.tableau.com/app/profile/q.nurlina.t/viz/FiberCo_Analysis/Dashboard1
